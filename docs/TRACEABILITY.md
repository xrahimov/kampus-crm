# TRACEABILITY.md

Every page, dialog and widget recorded in [EXPLORATION.md](EXPLORATION.md) (EXP), and where it lives in Kampus. Kampus is modelled on the reference's behaviour, not its code; URLs, names and layouts are Kampus's own.

Legend: **✓** built · **◐** built with a documented difference (see the assumption) · **✗** not built (reason given). "Code" lists the page under `src/app/[locale]`, the client feature folder under `src/features`, the services under `src/server/services` and the HTTP routes under `src/app/api/v1`. "Tests" names the Vitest file in `tests/unit` and the Playwright spec in `tests/e2e`.
